# justtrack-platform

Claude Code plugin that connects your agent to the justtrack platform MCP server.

- **Endpoint:** `https://mcp.justtrack.io/mcp`
- **Transport:** streamable HTTP

## Installation

```
/plugin marketplace add justtrackio/agents-marketplace
/plugin install justtrack-platform@justtrack
```

Run `/mcp` in Claude Code to check the connection status of the `justtrack` server.
